# Challenge #001 · 命令行待办清单

> 难度：入门 · 语言不限 · 建议 1–2 个晚上

## 目标

做一个能在终端运行的 Todo 工具。它不需要漂亮的界面，但要真的能用。

## 最低要求

- [ ] 添加任务
- [ ] 列出任务
- [ ] 标记完成
- [ ] 删除任务
- [ ] 数据保存到本地文件，重新运行后还在
- [ ] 有 `--help` 或等价的用法说明

## 加分项

- [ ] 按状态筛选：全部 / 未完成 / 已完成
- [ ] 给任务加优先级或截止日期
- [ ] 支持中文输入和输出
- [ ] 有单元测试
- [ ] 打包成单文件，或提供一键运行脚本
- [ ] README 里写清楚安装、运行和示例

## 验收

把下面这段流程跑通，并录屏或截图：

```text
添加：买牛奶
添加：写周报
列出：两条都在
完成：买牛奶
列出：买牛奶已完成，写周报未完成
删除：写周报
重新打开：只剩买牛奶
```

## 提交

到 [Show and Tell](https://github.com/ACMagnus/code-harbor/discussions/categories/show-and-tell) 发帖，标题格式：

```text
[Challenge 001] 你的作品名
```

正文包含：

- 一句话介绍
- 语言 / 技术栈
- 运行方式
- 仓库或代码链接
- 截图或录屏
- 一个踩坑

## 提示

- 先做最小可用版本，再考虑加分项。
- 数据文件不要提交到仓库；在 `.gitignore` 里排除。
- 不要在示例里写真实姓名、路径或密钥。
