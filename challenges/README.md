# 每周挑战

每周一道可以在一到两个晚上做完的小题。目标不是“卷”，而是让你有一个可以交付、可以被 review 的小作品。

## 规则

- 语言、框架不限。
- 允许查文档、用 AI 辅助，但请自己理解并说明用了什么。
- 做完发到 [Show and Tell](https://github.com/ACMagnus/code-harbor/discussions/categories/show-and-tell)，标题写 `[Challenge 001] 你的作品名`。
- 贴仓库、截图、运行方式，以及一个你踩过的坑。
- 不评比、不排名；重点是把东西做完。
