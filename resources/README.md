# 编程资源库

只收“真的会点开第二次”的资源。每条都写一句为什么值得看。

## 入门 / 通用

- [MDN Web Docs](https://developer.mozilla.org/zh-CN/) — Web 前端最稳的参考书，HTML/CSS/JS 遇到问题先查它。
- [freeCodeCamp](https://www.freecodecamp.org/chinese/) — 有中文课程和练习，适合零基础把 HTML/CSS/JS 跑一遍。
- [CS50](https://cs50.harvard.edu/x/) — 哈佛的计算机科学入门课，讲清算法、内存、数据结构，不是速成。
- [GitHub Skills](https://skills.github.com/) — 用真实仓库练 Git、Actions、Pages，比看视频记得牢。
- [roadmap.sh](https://roadmap.sh/) — 前端、后端、DevOps 的学习路线图，用来查漏，不要当唯一标准。

## 语言 / 工具

- [JavaScript.info](https://zh.javascript.info/) — 从基础到异步、原型、模块，讲得细，中文版可读。
- [Python 官方教程](https://docs.python.org/zh-cn/3/tutorial/) — 不花哨，但准确；遇到语法争议以它为准。
- [Rust Book](https://doc.rust-lang.org/book/) — 学 Rust 绕不开的官方书，所有权那一章值得读两遍。
- [Go Tour](https://go.dev/tour/) — 浏览器里直接跑，适合快速判断自己喜不喜欢 Go。
- [Pro Git](https://git-scm.com/book/zh/v2) — Git 不是只会 `add/commit/push`；版本历史和分支模型从这里补。

## 算法 / 计算机基础

- [VisuAlgo](https://visualgo.net/zh) — 把排序、图、树动起来看，比死记复杂度直观。
- [OI Wiki](https://oi-wiki.org/) — 竞赛向，但数据结构与算法条目很全，查概念方便。
- [计算机教育中缺失的一课](https://missing.csail.mit.edu/) — shell、编辑器、调试、版本控制，学校常不教但每天都用。

## 怎么用这份清单

- 一次只挑一个主资源，不要收藏十个然后都不看。
- 看完一小节就写一段代码或发一个 Show and Tell。
- 发现链接失效或内容过时，开 Issue 或 PR 修掉。
