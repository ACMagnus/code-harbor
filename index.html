04 / ONBOARDING
STEP 01

读规则

先看 START-HERE 和行为准则。知道边界，发言更自在。

STEP 02

打个招呼

说一句你在学什么、想做什么。不用写简历，也不用包装。

STEP 03

发第一个问题

目标、尝试、报错、环境。发出来，比在脑子里打转强。

RULES

友好，不等于没有边界。

05 / CODE OF CONDUCT
01

不人身攻击、不歧视、不嘲讽新手。对代码，不对人。

02

不灌水、不刷屏、不发与编程无关的广告。

03

不发布 API Key、密码、Cookie、身份证等敏感信息。

04

不传播盗版课程、破解软件和来源不明的二进制。

05

转载注明出处；引用代码注明许可。

完整规则

参与社区即表示同意行为准则。违规内容会被删除，反复违规会被移出社区。
