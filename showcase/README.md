# Show and Tell

这里放社区成员的作品：Demo、开源项目、脚本、设计、踩坑复盘。

## 怎么发

到 [Show and Tell](https://github.com/ACMagnus/code-harbor/discussions/categories/show-and-tell) 发帖，标题写：

```text
[Showcase] 作品名 · 一句话亮点
```

正文用 [作品模板](_template.md)，至少包含截图或在线链接，以及一个你踩过的坑。

## 什么可以发

- 自己写的项目，哪怕还没做完。
- 一个解决你实际问题的脚本。
- 一次失败的尝试和原因。
- 对某个开源项目的贡献。
- 一篇你认真写过的技术笔记。

## 什么不要发

- 纯广告、引流、课程分销。
- 没有说明的“帮我看看”链接。
- 包含密钥、Cookie、个人隐私的代码或截图。
- 盗版资源、破解工具。

## 点评方式

- 先说你看到了什么，再说建议。
- 建议具体到行为：命名、边界、错误处理、性能、可读性。
- 不嘲讽、不否定作者本人。
